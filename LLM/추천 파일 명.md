## 파일
| 추천     | 느낌 및 용도 | 추천 상황 |
| :--- | :--- | :--- |
| **PROGRESS.md** | 직관적이고 일반적임 | 전체적인 진행률이나 단계를 기록할 때 |
| **CHANGELOG.md** | 기술적이고 표준적임 | 모델 업데이트, SQL 쿼리 수정 등 변경 이력을 남길 때 |
| **DEVLOG.md** | 친근하고 상세함 | 개발 과정에서의 고민, 에러 해결 과정 등을 자유롭게 적을 때 |
| **ROADMAP.md** | 미래 지향적임 | 앞으로의 계획과 현재 어디까지 왔는지를 보여줄 때 |
| **SITREP.md** | 절도 있고 전문적임 | 현재 상황을 요약하여 보고서 형식으로 남길 때 (Situation Report) |
| **HISTORY.md** | 기록 중심적임 | 프로젝트의 과거부터 현재까지의 연대기를 적을 때 |
