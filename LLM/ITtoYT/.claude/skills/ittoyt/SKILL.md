# ITtoYT 파이프라인

IT 개념 하나 → 검증된 유튜브 콘텐츠 소재 2종(일반 + short).

## 실행 순서

### 0. 입력 확인
개념명과 slug를 정한다. slug는 영문 kebab-case (`IT 개념/<slug>/`).
사용자가 범위를 안 줬으면 스코프를 한 문장으로 제안하고 그대로 진행한다 — 확인을 기다리며 멈추지 않는다. 범위가 어긋나면 그때 되돌리는 게 더 빠르다.

이미 `IT 개념/<slug>/` 가 있으면 `meta.json` 의 `stage` 를 보고 **이어서** 진행한다. 처음부터 다시 하지 않는다.

### 1. 검증 — `it-verify` 스킬
`00-research.md` 산출. 이 단계를 건너뛰면 파이프라인 전체가 의미를 잃는다.

### 2. 소스팩 — `nlm-pack` 스킬
`10-source-long.md`, `20-source-short.md`, `30-checklist.md`, `meta.json` 산출.

### 3. 사용자에게 넘기기
아래 형식으로 보고한다:

```
✅ <개념명> 준비 완료

검증: 주장 N개 (확정 N / 통설 N / 논쟁 N / 미확인 N)
⚠️ 기억과 달랐던 점: <있으면 여기>

일반 버전: NotebookLM Explainer / 한국어 / <스타일>
short 버전: 경로 <A|B|C> — <이유>

다음 할 일: IT 개념/<slug>/30-checklist.md 열고 순서대로 진행
```

## 현재 자동화 경계

지금 이 파이프라인은 **NotebookLM 클릭 직전까지** 자동이다. 영상 생성 API가 존재하지 않아 그 지점이 경계다(`nlm-pack/references/notebooklm-settings.md` 참고).

의도적으로 아직 만들지 않은 단계 — 요청받으면 그때 붙인다:
- **영상 후처리**: 16:9 → 9:16 리프레임, 인트로/아웃트로, 자막 번인 (ffmpeg)
- **YouTube 메타데이터**: 제목 후보, 설명문, 태그, 챕터, 썸네일 문구
- **YouTube 업로드**: Data API + OAuth
- **브라우저 자동화**: NotebookLM UI 조작

이 단계들은 결정론적 작업이라 스킬보다 Python 스크립트가 맞다. `scripts/` 에 넣고 체크리스트에서 호출하는 구조를 예정하고 있다.

## 지키는 것

- **검증 없는 소스팩을 만들지 않는다.** 순서를 건너뛰자는 요청이 오면 위험을 한 줄로 말하고, 사용자가 그래도 원하면 진행한다.
- **한 개념 = 한 폴더.** 파일명 규칙(`00-`/`10-`/`20-`/`30-`)을 지킨다. 이후 자동화가 이 규칙에 의존한다.
- **팩트시트의 `영상에 쓰지 말 것` 은 소스팩에 넣지 않는다.**
