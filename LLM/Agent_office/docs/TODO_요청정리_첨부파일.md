## 고치는 방향 (작게)

1. **`draft_brief` 에 `files: list[str]` 인자 추가** (파일 이름만 — 내용은 넣지 않는다. 브리프는 보조 모델 1회라 짧게).
   - `brief_node` 에서 `attachments.files(state["tool_inputs"])` 의 이름 + (선택) 팀 양식 파일 칸 이름을 넘긴다.
   - 이름은 데이터이므로 `attachments._label()`(표시선 위조 방지·80자)처럼 정리해서 넣는다.
2. **프롬프트에 한 줄**: 파일이 있으면
   "- 사용자가 파일 N개를 첨부했다 (이름: …). 내용은 다음 단계에서 팀원에게 근거 자료로 그대로 들어간다.
      '자료가 없다·초안 미제공·플레이스홀더로 채운다' 같은 기준·제약을 만들지 말고, '첨부 문서를 근거로 한다'를 기준에 넣는다."
   파일이 없으면 지금 프롬프트 그대로 (다른 업무 영향 없음).
3. **assumptions(먼저 묻는 질문)** 도 '첨부가 있나요?' 류를 만들지 않게 — 위 문장으로 충분한지 테스트로 확인.

## 테스트 (가짜 모델 — `tests/fakes.py`)

- `draft_brief(..., files=["a.md"])` 가 보내는 메시지에 파일 이름과 '근거 자료로 들어간다' 문장이 있다 / `files=[]` 면 지금과 같은 메시지 (회귀 없음).
- `brief_node`: `tool_inputs={"attachments": [...], "attachments_names": [...]}` 이면 `draft_brief` 에 이름이 넘어간다 (가짜 모델의 받은 메시지로 확인).
- 파일 이름에 표시선(`<<<…>>>`)·줄바꿈이 있어도 한 줄로 정리돼 들어간다.
