# 📌 Agent Office — 직급형 멀티 에이전트 협업 시스템

**기간:** 2026-10-19 ~ 진행 중 (5일 동안 커밋 42개)
**역할:** 기획·설계·구현·테스트 (1인)
**저장소:** github.com/jeong-yun/Project (`LLM/Agent_office`)

## 한 줄 소개

사용자가 팀장(Supervisor)에게 원하는 최종 결과를 맡기면 전문가 에이전트들이 일을 나눠 쓰고, 상급자가 검토해 하나로 합칩니다. 결과는 비평가와 코드 검증(하네스)으로 확인합니다. 사람이 결과에 대해 묻거나 고친 뒤 채택하면, 그 판단이 에이전트별 교훈으로 쌓이는 멀티 에이전트 프레임워크입니다. 팀은 범용·주식·여행·IT 개념·음악·설계 6개입니다.

## 기술 스택

- LangGraph(Supervisor 트리, interrupt·체크포인트), LangChain, Streamlit
- LLM: OpenAI·Anthropic(API·구독 CLI)·Google·Upstage·무료 모델(FreeLLMAPI)
- 검증·최적화: OR-Tools CP-SAT, shapely
- 도면·3D: ezdxf, trimesh, IFC
- 음악: Gemini Lyria, pedalboard
- 데이터·테스트: SQLite, pytest(모의 모델)

## 주요 구현 및 성과

### 1. 멀티 에이전트 구조와 검증 체계

- 일렬로 이어지던 직급 검토를 Supervisor → Specialist 트리로 다시 설계했습니다. 이 구조에 적대적 검토, 비평가(LLM-as-a-Judge), 자가 교정, 코드 하네스(Backtracking)를 붙였습니다.
- 단계별 평가 하네스(PRM/ORM)로 실패한 단계를 짚어 2번 고쳤습니다. 결과는 **PRM 33%·ORM 실패 → PRM 100%·ORM 통과**입니다.
- 실행 기록을 분석해 두 문제를 찾았습니다.
  - 비평가 불합격률이 **75%**였습니다.
  - 자가 교정 뒤 비평 점수가 4점에서 2점으로 떨어졌는데, 낮은 쪽이 최종 답으로 나갔습니다.
  - 그래서 가장 점수가 높은 답을 남기는 방식과 심각도에 따른 합격 기준을 넣었습니다.

### 2. 속도와 안정성

- 형제 에이전트와 자료 조사를 동시에 실행하는 스케줄러를 만들었습니다. 가짜 모델 벤치마크에서 전체 실행 시간이 **6.35초 → 3.25초(−49%)**로 줄었습니다.
- 4개 provider에서 장애, 크레딧 부족, 할당량 초과가 나도 자동으로 다른 모델로 넘어가 모든 에이전트가 응답을 유지했습니다(실측). 재시도, 대안 모델, 쿨다운 순서로 처리합니다.
- 유료 키 없이 무료 모델만으로도 전 과정을 실행할 수 있게 했습니다.
- 팀장 모델에 Claude 구독(`claude -p`) provider를 추가했습니다. API 비용 없이 Opus를 쓸 수 있고, 구조화 출력도 실제로 확인했습니다.

### 3. 결정론적 검증 — LLM이 쓴 숫자를 코드로 다시 계산

- 주식 팀: 가중 점수, 손익비, 평균 단가를 코드로 다시 계산합니다. 틀리면 정답 값을 주고 다시 쓰게 합니다. 삼성전자 실측에서 검산이 일치했고 **PRM 100%·ORM 통과**했습니다.
- 여행 팀: 오사카 3박 4일 일정이 달력·요일과 맞는지 검증해 **PRM 100%·ORM 통과**했고, 경로 지도도 만듭니다.

### 4. 전문 팀 확장 (팀 하나 = YAML 설정 + 도구)

- **설계 팀:**
  - 역할 분담: LLM은 방 구성만 정하고, CP-SAT 엔진이 좌표를 계산하며, 코드가 동선·채광·복도를 검증합니다.
  - 출력: DXF, PNG, SVG, GLB, STL, IFC 파일과 후보안 A/B/C를 만듭니다.
  - 개선 1: 같은 표본에서 기존 방식은 검증 오류가 **5건**이었는데, 새 엔진은 **0건**입니다.
  - 개선 2: 외곽 효율이 **67% → 100%**로 올랐습니다. 요청하지 않은 빈 공간도 **162㎡ → 0㎡**로 없앴습니다.
- **음악 팀:**
  - Gemini Lyria로 곡을 만들고, Gemini가 직접 듣고 채점합니다.
  - 편집은 자연어로 요청하면 허용된 연산만 담은 계획으로 바꿔 CPU에서 실행합니다.
  - 음량은 목표의 **±1.5 LUFS** 안에 맞췄습니다.
- **IT 개념 팀:** 카탈로그를 **170개 → 148개**로 정리하고 요약 누락을 **33건 → 0건**으로 줄였습니다. 수정은 검증, 사람 승인, GitHub 커밋까지 자동으로 이어집니다.

### 5. 운영과 관측

- 모든 LLM 호출의 토큰과 추정 비용을 모델별·API 키별로 집계합니다. 키는 원문 대신 지문만 저장합니다.
- AI 뉴스와 SNS를 수집해 브리핑과 개선 아이디어 카드로 보여 줍니다. 실측 비용은 **회당 약 $0.02**입니다. 프롬프트 주입 방지와 과장 광고 표시를 넣었습니다.
- 전체 화면 브리핑 보드(TV·키오스크용)를 만들었습니다.
- 교훈을 개인 정보를 뺀 상태로 GitHub에 동기화합니다. 새 PC에서도 학습한 내용을 이어 쓸 수 있습니다.

### 6. 품질 관리

- API 키와 네트워크 없이 도는 자동 테스트가 **380건**입니다(모의 LLM, 가짜 Lyria, 가짜 비전 모델).
