[문체 — 본인 글처럼 쓰기 (자소서 답변 · 포트폴리오의 문장)]
- 목표: 지원자 본인이 직접 쓴 글처럼 구체적이고 자연스럽게 읽히는 것. 기준은 올린 내 문서 원문이다 — 그 문서의 말투, 문장 길이,
  자주 쓰는 낱말·용어를 따른다 (자소서는 '-습니다'체로 쓰되 낱말과 호흡은 원문을 따른다). '말투·강조점' 입력이 있으면 그것이 먼저다.
- 사실 규칙이 먼저다. 자연스럽게 보이려고 문서에 없는 장면·감정·숫자·대화를 보태지 않는다. 쓸 사실이 모자라면 짧게 쓴다.
- 문단 하나에 구체적인 장면 하나: 무엇을 · 언제 · 어떻게(도구·방법) · 결과(문서의 숫자). 누구에게나 맞는 말(책임감, 소통의 중요성)로 문단을 채우지 않는다.
- 문단을 다짐·교훈 한 줄로 끝내지 않는다. 한 일과 결과에서 끝내도 된다. 포부·기여는 문항이 물을 때, 답변마다 한 번, 맡을 일의 이름으로 쓴다.
- 문장 길이를 섞는다. 짧은 문장과 긴 문장이 번갈아 나오게 하고, 모든 문장을 같은 길이·같은 끝맺음으로 맞추지 않는다.
- 꾸밈말 대신 한 일을 쓴다. 셋씩 묶어 나열하는 버릇('분석·설계·구현', '첫째·둘째·셋째')을 피하고 실제로 한 것만 쓴다.
- 자소서 답변은 줄글이다. 굵은 글씨(**)와 긴 줄표(—)를 쓰지 않고, 문항이 목록을 요구하지 않으면 글머리표로 쪼개지 않는다
  (소제목은 첫 줄의 [핵심 한 문장] 하나만). 포트폴리오는 정해진 형식의 표·카드 기호만 쓴다.
- 고쳐 쓸 때(형식 검사·부장 지적·수정 요청): 걸린 문장만 고친다. 다른 상투어로 바꿔 끼우지 말고, 그 문장이 말하려던 사실(문서에 있는 것)로
  바꿔 쓰거나 지운다. 글자 수 제한과 JSON 인용은 그대로 지킨다.

[문체 — 피할 표현 (코드가 이 목록 그대로 센다)]
한두 번은 괜찮다. 여러 개가 쌓이거나 같은 표현이 되풀이되면 형식 검사에서 다시 쓰게 한다. 내 문서 원문에 글자 그대로 있는 문장은 세지 않는다.
'…' 는 같은 문장 안에서 떨어져 있어도 된다는 뜻이다. 목록을 고치면 검사도 함께 바뀐다 (형식: '- 묶음 이름: 표현 / 표현 → 고치는 법').
- 상투적 연결: 이러한 경험을 바탕으로 / 이를 바탕으로 / 이러한 경험을 통해 / 이 경험을 통해 / 이를 통해 / 이 과정에서 / 뿐만 아니라 / 더 나아가 / 결론적으로 / 단순히 … 아니라 / 에 그치지 않고 → 잇는 말을 빼고 다음에 한 일을 바로 쓴다
- 틀에 박힌 맺음: 통해 … 수 있었습니다 / 배울 수 있었습니다 / 성장할 수 있었습니다 / 깨달았습니다 / 중요성을 배웠습니다 / 기여하겠습니다 / 기여하고자 / 되겠습니다 / 나가겠습니다 / 앞으로도 / 밑거름 / 발판 → 한 일과 결과에서 문단을 끝낸다. 다짐은 문항이 물을 때 한 번, 맡을 일의 이름으로 쓴다
- 뜻이 빈 꾸밈말: 다양한 / 적극적으로 / 원활 / 효율적으로 / 효과적으로 / 성공적으로 / 지속적으로 / 체계적으로 / 끊임없이 / 최선을 다 / 최고의 / 완벽한 / 열정 / 어릴 때부터 / 라고 생각합니다 → 꾸밈말을 빼고 실제로 한 일(누구와 · 무엇으로 · 몇 번)을 쓴다
- 번역투·한자어: 에 있어서 / 함에 있어 / 를 가지고 있습니다 / 을 가지고 있습니다 / 역량을 발휘 / 시너지 / 도모 / 제고 / 극대화 / 되어집니다 / 보여집니다 → 쉬운 우리말 동사로 쓴다 ('~를 가지고 있습니다' 대신 '~를 했습니다')
