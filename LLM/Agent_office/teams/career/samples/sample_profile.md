- 학력: 가상대학교 컴퓨터공학과 졸업 (2021.02)

## 경력 · 프로젝트

### 1. 보안 로그 분석 자동화 (2022.04 ~ 2022.12)
- 문제: 관제 요원이 매일 아침 방화벽·웹 로그를 수작업으로 분류하느라 하루 평균 3시간이 걸렸다.
- 역할: 4명 팀에서 분석 스크립트 설계와 개발을 맡았다.
- 기술: Python, pandas, Elasticsearch
- 결과: 일일 분류 시간을 180분에서 45분으로 줄였다. 오탐으로 닫던 이벤트를 하루 1,200건 자동 분류했다.
- 배운 점: 규칙을 코드로 남기면 사람이 바뀌어도 품질이 유지된다.

### 2. 이상 접속 탐지 모델 시범 적용 (2023.03 ~ 2023.10)
- 문제: 정해진 임계치만으로는 계정 탈취 의심 접속을 늦게 찾았다.
- 역할: 데이터 준비와 모델 평가를 맡았다 (모델 설계는 선임과 함께).
- 기술: Python, scikit-learn(Isolation Forest), SQL
- 결과: 시범 기간 동안 기존 규칙이 놓친 의심 접속 17건을 찾았고, 그중 5건이 실제 계정 공유로 확인됐다.
- 배운 점: 탐지 결과를 운영자가 이해할 수 있게 근거(피처)를 함께 보여 줘야 쓰인다.

### 3. ISMS-P 인증 심사 증적 준비 지원 (2024.05 ~ 2024.09)
- 역할: 접근권한 검토와 로그 보관 항목의 증적(설정 화면·로그 보관 현황표)을 모아 정리했다.
- 결과: 담당 항목에서 결함 지적 0건.
- 배운 점: 기술 설정이 정책 문장과 같은 말을 하는지 대조하는 습관이 생겼다.

### 4. 클라우드 로그 수집 파이프라인 개선 (2025.02 ~ 2025.06)
- 기술: AWS CloudTrail, S3, Python, Airflow
- 결과: 수집 누락을 하루 평균 2.3%에서 0.4%로 줄였다.
