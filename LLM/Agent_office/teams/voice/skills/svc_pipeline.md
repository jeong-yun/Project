노래 음색 변환(SVC) 안내는 아래 내용(원본: `teams/voice/assets/` 의 `preprocess.py` · `svc_colab_training.ipynb` · `README.md` · `run.bat`)만 근거로 쓴다. 여기에 없는 옵션·숫자는 지어내지 말고 '원본 파일에 없음' 또는 '재 보지 않음'이라고 쓴다.

## 0. 먼저 지킬 것 (책임 있는 사용)

- 목소리 출처를 먼저 확인한다: 내 목소리 / 본인 동의를 받은 사람의 목소리 / 사용이 허락된 공개 데이터셋. 확인이 없으면 학습 계획·노트북을 만들지 않고, 동의를 받는 방법(누구에게, 무엇에 쓴다고)을 안내한다.
- 실존 가수·유명인의 목소리를 동의 없이 학습·공개하면 퍼블리시티권 등 권리 침해가 될 수 있다 (원본 README·노트북도 '본인 동의 필요'라고 적고 있다). 이런 요청은 돕지 않는다. 그 가수의 노래를 **내 목소리로** 부른 커버를 만드는 것은 괜찮다.
- 다른 사람인 척 남을 속이는 데(전화·음성 메시지, 본인 인증 통과·우회) 쓰는 요청은 범위 밖이다. 실행 방법을 하나도 주지 않고, 왜 돕지 않는지만 쓴다.
- 결과물을 남에게 보이거나 올릴 때는 'AI 로 합성한 음성'이라고 표시하라고 안내한다.
- 이 팀은 **노래 음색 변환**만 다룬다. 말하는 목소리 합성(TTS)·실시간 목소리 변환은 이 파일들의 범위가 아니다. 말하는 녹음(낭독·대화)의 목소리 바꾸기는 🗣 일상 말 음성 변환 팀이 맡는다.

## 1. 전체 흐름

| 단계 | 어디서 | 무엇을 |
|---|---|---|
| 전처리 A안 (권장) | 내 PC | `run.bat` 더블클릭 또는 `python preprocess.py --input <음원 폴더> --singer <화자>` (`--fast`: 빠른 모델) → `dataset_raw/<화자>/*.wav` |
| 올리기 | Google Drive | `dataset_raw` 폴더를 `dataset_raw.zip` 으로 묶어 `MyDrive/svc_project/` 에 올림 (B안은 원본 곡 `songs.zip`) |
| 학습 | Colab (T4 GPU) | `svc_colab_training.ipynb` 셀 순서대로 |
| 변환 | Colab | 바꿀 노래의 보컬만 분리한 wav 를 `svc_project/cover.wav` 로 올리고 11번 셀 (음높이 자동 예측 끔 `-na`) |
| 합치기 | 오디오 편집기 | 변환된 보컬(`cover_converted.wav`)과 반주를 합침 |

## 2. 전처리 (`preprocess.py`)

- 받는 음원: mp3·wav·flac·m4a. 단계: (0) 필요한 패키지 확인·자동 설치(numpy·soundfile·audio-separator — 첫 설치는 수백 MB, 인터넷 필요), ffmpeg 가 없으면 imageio-ffmpeg 로 설치 → (1) ffmpeg 로 44.1kHz 스테레오 wav 변환 → (2) audio-separator 로 보컬 분리 → (3) 무음 기준 자르기.
- 보컬 분리 모델: 기본 `model_bs_roformer_ep_317_sdr_12.9755.ckpt`(BS-RoFormer, 품질 우선, GPU 권장 — CPU 면 느림) / `--fast` 는 `UVR-MDX-NET-Voc_FT.onnx`(MDX-Net, 속도 우선, GPU 없는 PC 에 권장). 모델은 첫 실행 때 자동으로 내려받는다.
- 자르기 기준 (`slice_wav` 기본값): 10ms 단위 소리 크기가 −40dB 보다 크면 소리 있음, 0.3초보다 짧은 무음은 이어 붙임, 앞뒤 0.1초 여유, 15초보다 길면 15초씩 나눔, 2초보다 짧은 조각은 버림. 결과는 모노 16비트 wav.
- 인자 없이 실행하면 음원 폴더·가수 이름·빠른 모델 여부(y/N)를 묻는 대화형으로 돈다. `--out` 으로 결과 상위 폴더를 바꿀 수 있다 (기본: 현재 폴더). 작업 파일은 `_work/` 에 남는다.
- 끝나면 총 클립 수와 분량을 알려 주고, 10분 미만이면 '30분~1시간 이상 권장' 경고를 띄운다.
- 걸리는 시간: GPU 없는 PC 의 보컬 분리는 곡당 수 분~수십 분 (원본 안내 문구). 급하면 `--fast` 또는 Colab B안.

## 3. 학습 데이터 기준

- 분량: 보컬만 남긴 길이로 **30분~1시간 이상 권장, 10분 미만은 부족** (원본 README·preprocess.py).
- 클립: 5~15초 클립을 만든다 (2초 미만은 버리고 15초 초과는 나눈다). 반주가 남지 않게 보컬만 분리한다.
- '🔍 데이터 점검'은 코드가 이 기준으로 클립 수·총 길이·클립 길이·거의 무음·클리핑 의심을 센다. 판정: 화자별 10분 미만 부족 · 30분 미만 주의 · 그 이상 충분.

## 4. Colab 노트북 셀 순서 (`svc_colab_training.ipynb`)

시작 전에 `런타임 → 런타임 유형 변경 → T4 GPU` 를 고른다.

| 셀 | 하는 일 |
|---|---|
| 1 | GPU 확인 (`nvidia-smi`, GPU 런타임이 아니면 멈춤) |
| 2 | Google Drive 연결 + 작업 폴더 `MyDrive/svc_project` |
| 3 | `pip install -U so-vits-svc-fork` (2~3분). 뒤 셀에서 import 오류가 나면 런타임을 다시 시작하고 1~3번 셀부터 |
| 4 | [A안] Drive 의 `dataset_raw.zip` 풀기 |
| 5 | [B안] `songs.zip` 풀고 BS-RoFormer 로 보컬 분리 (Colab GPU 로 곡당 약 1분 — 원본 설명의 어림값) |
| 6 | [B안] 무음 기준 자르기 → `dataset_raw/<SINGER>/` (`SINGER` 값을 화자 이름으로) |
| 7 | `svc pre-resample` → `svc pre-config` → `svc pre-hubert -fm crepe` (리샘플·설정 만들기·HuBERT/f0 특징) |
| 8 | 학습 설정: `epochs = 400` (데이터 30분~1시간 기준, 부족하면 늘려서 다시 실행 — 이어서 학습됨), `batch_size = 16` (T4 기준, 메모리 부족(OOM)이면 8) |
| 9 | `svc train --model-path "{WORK}/logs/44k"` — 체크포인트를 Drive 에 저장. 사전 학습 기반 모델을 자동으로 받아 이어서 학습 |
| 10 | (선택) TensorBoard 로 학습 곡선 보기 |
| 11 | 변환: 가장 최근 `G_*.pth` 로 `svc infer cover.wav -fm crepe -na -t 0 -o cover_converted.wav` — `-na` 는 맞춤 노트북이 더한 것 (원본 셀은 옵션이 없어 fork 기본값인 '자동 예측 켜짐'으로 돌았다) |
| 12 | 결과 듣기 |

A안이면 5~6번 셀을, B안이면 4번 셀을 건너뛴다.

## 6. 변환 옵션

- 음높이 자동 예측: 노래는 **끈다 (`-na`)**. 원조 so-vits-svc README 는 `--auto_predict_f0` 를 '노래(singing voice)를 변환할 때는 켜지 마라 — 심한 음높이 문제'라고 적었고, so-vits-svc-fork 의 `svc infer` 는 `-a/-na` 기본값이 켜짐이라 적지 않으면 켜진 채 돈다. 그래서 맞춤 노트북 11번 셀에 `-na` 를 적었다. 노래 계획·답에서 `-a`(켜기)를 권하지 않는다 — 자동 예측은 말 변환(🗣 일상 말 음성 변환 팀)용이다.
- 키 조절 `-t`: 반음 단위 (fork 기본값 0, 12 = 한 옥타브 — fork 화면 안내 'Pitch (12 = 1 octave) … when Auto predict F0 is turned off'). 자동 예측을 껐으므로 변환할 보컬의 멜로디를 따르고 `-t` 만큼 옮긴다. 키를 바꾸려면 11번 셀의 `-t 0` 을 반음 수로 바꿔 다시 실행한다. 원래 부른 사람과 성별이 다르면 `-12` 또는 `+12` 를 먼저 해 본다 (원본 노트북 11번 셀). 남자 목소리 모델로 여자 노래를 바꾸면 보통 내리는 쪽(−)을, 여자 목소리 모델로 남자 노래를 바꾸면 올리는 쪽(+)을 먼저 들어 본다. 그 밖의 세부 값은 들어 보고 고친다 (재 보지 않음).
- f0 방식: 원본은 특징 추출과 변환 모두 `-fm crepe` 를 쓴다. 학습과 변환에서 같은 방식을 쓴다.
- 반주: 변환된 보컬과 반주를 오디오 편집기에서 합친다 (원본 노트북). 앱의 🎵 음악 팀은 새 곡을 만드는 팀이라 이 합치기를 대신하지 않는다.

## 7. 이 앱이 하는 일과 하지 않는 일

- 한다: 실행 계획, 양식 값(화자 이름·A/B안·epochs·batch_size)을 넣은 맞춤 노트북·안내·원본 스크립트 묶음(zip), 올린 `dataset_raw.zip` 의 숫자 점검, 붙여 넣은 학습 로그의 손실 추이 진단(📈 — 모델 없이 코드만).
- 하지 않는다: 보컬 분리·학습·변환 실행 (이 PC 에는 GPU·필요한 패키지가 없고, 앱은 패키지를 설치하지 않는다). 음원 내용을 모델로 보내지 않는다 — 숫자 요약만 근거 자료가 된다.
