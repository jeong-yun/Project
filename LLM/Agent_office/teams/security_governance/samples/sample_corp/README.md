# 샘플상사 (가상 회사) 증적

보안 거버넌스 팀 시험용 **가상** 증적이다. 실제 회사·사람·IP 와 관계없다.

- 회사 이름 '샘플상사', 사용자 이름(user01 …), 호스트 이름(*.example.com)은 지어낸 것이다.
- IP 는 문서 전용 대역(RFC 5737: 192.0.2.0/24 · 198.51.100.0/24 · 203.0.113.0/24)만 쓴다.

| 폴더 | 내용 |
| --- | --- |
| `current/policy` | 정보보호 정책 발췌 (비밀번호·접근권한 검토·로그·백업) |
| `current/config` | 이번 주 설정: sshd, 방화벽 규칙, IAM 비슷한 JSON |
| `current/logs` | 인증 로그 일부, 3분기 접근권한 검토 기록 |
| `previous/config` | 지난주 설정 — `current/config` 와 비교하면 drift 가 보인다 |

일부러 넣어 둔 미비점(점검 팀이 찾아야 할 것):

1. sshd 에서 비밀번호 로그인을 다시 켰다 (지난주 `no` → 이번 주 `yes`).
2. 방화벽에 원격 데스크톱(3389) 전체 허용 규칙이 새로 생겼다.
3. 퇴사자 계정(user07)이 IAM 에 남아 있고, 접근권한 검토 기록에도 '조치 예정'으로만 적혀 있다.
4. 서비스 계정 키가 400일 넘게 교체되지 않았다 (정책은 90일).
5. 정책은 로그를 1년 보관하라고 하지만 로그 설정은 180일이다.
6. 관리자 user02 의 MFA 가 꺼졌다 (지난주 `true` → 이번 주 `false`), 그 계정이 관리망 밖(203.0.113.77)에서 비밀번호로 로그인했다.
