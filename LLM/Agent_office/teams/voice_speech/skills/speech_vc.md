일상 말 음성 변환 안내는 아래 내용만 근거로 쓴다. 도구·노트북은 🎤 노래 음색 변환 팀과 같다 (so-vits-svc-fork, 원본: `teams/voice/assets/` 의 `preprocess.py` · `svc_colab_training.ipynb` · `README.md` · `run.bat`).
말에서 달라지는 점은 공식 문서(so-vits-svc-fork README·명령 도움말, 원조 so-vits-svc README — 2026-11-16 읽음)에서 확인한 것만 쓴다. 여기에 없는 옵션·숫자는 지어내지 말고 '확인 못 함' 또는 '재 보지 않음'이라고 쓴다.

## 0. 먼저 지킬 것 (책임 있는 사용 — 말은 노래보다 사칭 위험이 크다)

- 목소리 출처를 먼저 확인한다: 내 목소리 / 본인 동의를 받은 사람의 목소리 / 사용이 허락된 공개 데이터셋. 확인이 없으면 학습 계획·노트북을 만들지 않고, 동의를 받는 방법(누구에게, 무엇에 쓴다고)을 안내한다.
- 다음 요청은 돕지 않는다. 실행 방법을 하나도 주지 않고, 왜 돕지 않는지와 다음에 할 일만 쓴다.
  - 다른 사람인 척 전화·음성 메시지 보내기 (가족·상사·기관 직원 행세, 보이스피싱)
  - 가짜 녹취·통화 녹음·증거 만들기, 실제 사람이 말한 것처럼 꾸미기
  - 목소리로 하는 본인 인증(은행·ARS·화자 인식) 통과·우회
  - 동의 없는 다른 사람·유명인·정치인 목소리 복제
- 결과물을 남에게 보이거나 들려줄 때는 'AI 로 합성한 음성'이라고 표시하라고 안내한다.
- 이 팀은 **말하는 녹음의 목소리 바꾸기(음성 변환)** 만 다룬다. 글을 읽어 주는 음성 합성(TTS)은 이 도구로 할 수 없다 (원조 so-vits-svc README: TTS 기능 없음). 실시간 변환(`svc vc`)은 사칭에 바로 쓰일 수 있어 다루지 않는다. 노래 커버는 🎤 노래 음색 변환 팀.

## 1. 노래와 무엇이 같고 무엇이 다른가

| 항목 | 노래 (🎤 팀, 원본 노트북) | 말 (이 팀) | 근거 |
|---|---|---|---|
| 도구 | so-vits-svc-fork | 같음 (새로 설치할 것 없음) | 원조 README: 학습 때 f0 예측기도 함께 학습돼 말 변환에 음높이 자동 예측을 쓸 수 있다 |
| 보컬 분리 | 늘 함 (반주 제거) | **배경 음악이 섞였을 때만** (A·B안). 없으면 분리하지 않음 (C안) | fork README: BGM 이 있으면 제거하라 |
| 자르기 | `preprocess.py`/B안 셀: −40dB, 2초 미만 버림, 15초씩 | C안: `svc pre-split` (기본 10초 이하 조각, 짧은 조각을 버리지 않음) · A·B안은 노래와 같음 | fork README: 한 화자의 긴 녹음은 `svc pre-split`, 명령 기본값 `--max-length 10` |
| 클립 길이 | 5~15초 | 같음 (C안은 10초 이하) | fork README '파일당 10초 이하', 원조 README '5~15초 권장' |
| 분량 | 10분 미만 부족 · 30분~1시간 이상 권장 | **같은 값을 빌려 씀 — 말에 맞는 기준은 확인 못 함** | 원본 preprocess.py·README (노래용) |
| 특징 추출 | `svc pre-hubert -fm crepe` | 같음 (말에 더 맞는 f0 방식은 확인 못 함) | 원본 노트북 7번 셀 |
| epochs · batch_size | 400 · 16 (OOM 이면 8) | **같은 값 — 말에 맞는 값은 확인 못 함** | 원본 노트북 8번 셀 |
| 변환 | `svc infer cover.wav -fm crepe -na -t 0` (자동 예측 끔) | `svc infer speech.wav -fm crepe -a -t 0 -o speech_converted.wav` | 원조 README: `--auto_predict_f0` 는 말용, 노래에는 켜지 마라 |
| 키 조절 | `-t` 로 반음 단위 (성별이 다르면 ±12) | 자동 예측을 켜면 `-t 0` 그대로 | fork 화면 안내: 자동 예측을 끈 경우에 맞추라 |
| 반주 합치기 | 함 | 없음 | — |

## 2. 전체 흐름 (C안 — 배경 음악 없는 녹음, 기본)

| 단계 | 어디서 | 무엇을 |
|---|---|---|
| 녹음 모으기 | 내 PC | 조용한 곳에서 한 사람이 말한 녹음(wav·mp3 등). 다른 사람 목소리·음악이 섞이지 않게 |
| 올리기 | Google Drive | 녹음 파일을 `speech.zip` 으로 묶어 `MyDrive/svc_project/` 에 올림 |
| 자르기 | Colab | 맞춤 노트북의 '4-C' 셀: `speech.zip` 풀기 → `svc pre-split` → `dataset_raw/<화자>/` |
| 학습 | Colab (T4 GPU) | 7~9번 셀 (노래와 같음) |
| 변환 | Colab | 바꿀 말 녹음을 `svc_project/speech.wav` 로 올리고 11번 셀 (`-a` 켬) |

배경 음악이 섞인 녹음이면 노래 팀과 같은 A안(내 PC `preprocess.py`) 또는 B안(Colab 5~6번 셀 — 이때 원본 곡 묶음 이름은 `songs.zip`)으로 보컬을 분리한 뒤 자른다.

## 3. Colab 셀 순서 (맞춤 노트북)

| 셀 | 하는 일 |
|---|---|
| 1~3 | GPU 확인 · Drive 연결 · `pip install -U so-vits-svc-fork` (2~3분) |
| 4 | [A안] `dataset_raw.zip` 풀기 — C안이면 건너뜀 |
| 4-C | [C안] `speech.zip` 풀기 → `svc pre-split -i /content/speech_raw -o /content/dataset_raw` (C안을 고른 묶음에만 있음) |
| 5~6 | [B안] 보컬 분리 → 자르기 — C안이면 건너뜀 |
| 7 | `svc pre-resample` → `svc pre-config` → `svc pre-hubert -fm crepe` |
| 8 | 학습 설정 `epochs`·`batch_size` (코드가 넣은 값 그대로) |
| 9 | `svc train` — 체크포인트를 Drive 에 저장, 끊기면 1~3번 셀 뒤 이 셀만 다시 |
| 10 | (선택) TensorBoard |
| 11 | 변환: `svc infer "{WORK}/speech.wav" ... -fm crepe -a -t 0 -o "{WORK}/speech_converted.wav"` |
| 12 | 결과 듣기 (`speech_converted.wav`) |

## 4. 흔한 문제와 조치

| 문제 | 조치 |
|---|---|
| Colab 세션이 끊김 | 다시 연결 → 1~3번 셀 → 9번 셀만 다시 (Drive 의 마지막 체크포인트에서 이어짐 — 원본 노트북) |
| 학습 중 메모리 부족(OOM) | 8번 셀 `batch_size` 를 8 로 (원본 노트북) |
| 2초 미만 조각이 많음 (C안) | `svc pre-split` 은 짧은 조각을 버리지 않는다 (명령 코드 확인). 숨소리·짧은 감탄사 조각은 지워도 된다 — 품질 효과는 재 보지 않음 |
| 음높이가 들쭉날쭉 | 11번 셀에 `-a` 가 있는지 확인한다. 그 밖의 해법은 확인 못 함 — 데이터 분량·무음·클리핑(🔍 데이터 점검)을 먼저 본다 |
| 쇳소리·끊김 | 원본 파일에 정해진 해법은 없다. 확인할 순서만: ① 변환할 녹음에 음악·잡음이 섞였는지 ② 학습 데이터 분량·무음·클리핑 ③ 학습을 더 이어 했는지. 효과는 재 보지 않았다고 밝힌다 |

## 5. 이 앱이 하는 일과 하지 않는 일

- 한다: 실행 계획, 양식 값(화자 이름·A/B/C안·epochs·batch_size·말 변환 명령)을 넣은 맞춤 노트북·안내·원본 스크립트 묶음(zip), 올린 `dataset_raw.zip` 의 숫자 점검.
- 하지 않는다: 자르기·학습·변환 실행 (이 PC 에는 GPU·필요한 패키지가 없고, 앱은 패키지를 설치하지 않는다). 녹음 내용을 모델로 보내지 않는다 — 숫자 요약만 근거 자료가 된다.
