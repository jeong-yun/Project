# 7. 참고 예시 마스킹 제안 (설계안, 코드 아님)

> 위험 등록부 [R05](03_위험_등록부.md#r05-참고-예시의-민감값-외부-전달) 의 계획한 통제다. 이 문서는 설계 제안이며 파이프라인 코드는 바꾸지 않았다.

## 7.1 목적

참고 예시(`existing_examples`)는 생성 모델이 '비슷하지만 똑같지 않은' 샘플을 만들도록 돕는다. 예시에 필요한 것은 **공격 부분의 모양**(경로·파라미터·페이로드 구조)이지 Host·쿠키·인증값 같은 환경 값이 아니다.
그래서 예시를 LLM 에 보내기 전에 환경 값과 민감값을 **자리표시 값으로 바꾸고**, 바꾼 뒤에도 룰 조건을 만족하는지 다시 확인한다.

원칙:
- **기본값 켬.** 끄려면 설정에서 명시적으로 끈다.
- **실패하면 막는다(fail closed).** 마스킹 중 오류가 나면 그 예시는 보내지 않는다.
- **원래 값은 어디에도 남기지 않는다.** 로그·`meta.json` 에는 바꾼 개수만.

## 7.2 넣을 곳

| 후보 | 위치 | 장점 | 단점 |
| --- | --- | --- | --- |
| **A (추천)** | [`3_1_prepare_requests.py`](../../3_1_prepare_requests.py) 133행, `existing_examples=ex.get("examples", [])[:n_ex]` 를 만드는 곳 | 요청 파일에 들어가기 직전 한 곳. 생성(3.2)·검토(3.3) 모두 이 요청 파일을 쓰므로 한 번에 둘 다 막힘 | `coverage.json` 에는 원래 예시가 남음 (로컬 파일) |
| B (보조) | [`3_1a_existing_coverage.py`](../../3_1a_existing_coverage.py) 194행, `c["examples"].append(text)` | 로컬 `coverage.json` 에도 마스킹된 예시만 남음 | 설정을 바꾸면 3.1a 를 다시 돌려야 함 (3.1a 는 입력이 그대로면 건너뜀) |

- 마스킹 함수는 [`3_0a_common.py`](../../3_0a_common.py) 에 `mask_example(text, rule) -> (masked_text, n_masked)` 로 두고 A 에서 부른다 (B 는 선택).
- 설정 한 줄을 [`LLM_설정.md`](../코드참조/LLM_설정.md) `## 실행` 표에 추가: `참고 예시 마스킹 | 예 | 예 = 보내기 전에 Host·쿠키·인증값·IP·이메일·토큰을 자리표시 값으로 바꿈, 아니오 = 그대로` (`C.run_yes(run, "참고 예시 마스킹")`).
- 표준 라이브러리만 쓴다 (`re`, `ipaddress`) — 이 프로젝트의 1.x·3.x 규칙과 같다.

## 7.3 바꿀 값

자리표시 값은 생성 지시문의 안전 규칙(문서용 IP·`example.com`)과 맞춘다. 그러면 학습 로그를 만들 때(1.4 '문서용 주소 바꾸기') 샘플마다 다른 값으로 다시 바뀐다.

| 대상 | 찾는 방법 | 바꾼 값 |
| --- | --- | --- |
| `Host` 헤더 값 | 헤더 줄 `Host:` | `www.example.com` (포트는 유지) |
| `Cookie` 헤더 | 헤더 줄 `Cookie:` | 이름은 두고 값만 `x` 로 (`SESSIONID=x; lang=x`) |
| `Authorization`, `Proxy-Authorization` | 헤더 줄 | 방식만 남김: `Bearer TOKEN`, `Basic dXNlcjpwYXNz`(user:pass) |
| `X-Forwarded-For`, `X-Real-IP`, `Forwarded`, `Referer`·`Origin` 의 호스트 | 헤더 줄 | IP 는 아래 규칙, 호스트는 `example.com` |
| IPv4 / IPv6 (요청 줄·헤더·본문 어디든) | `ipaddress` 로 검증되는 문자열 | `192.0.2.<n>` / `2001:db8::<n>` (같은 예시 안의 같은 값은 같은 값으로) |
| 이메일 | `[\w.+-]+@[\w-]+(\.[\w-]+)+` | `user@example.com` |
| JWT | `eyJ[\w-]+\.[\w-]+\.[\w-]*` | `eyJ0eXAiOiJKV1QifQ.e30.x` 같은 고정 더미 |
| 이름이 비밀인 파라미터·필드 값 | 이름이 `token`, `access_token`, `api_key`, `apikey`, `key`, `secret`, `session`, `sid`, `password`, `passwd`, `pwd`, `auth` (대소문자 무시) 인 쿼리·폼·JSON 값 | 같은 길이의 `x` (최대 16자) |
| 긴 무작위 값 | 32자 이상의 16진수·base64 덩어리 | 같은 종류의 고정 더미 |

**바꾸지 않는 것**: 메서드·경로·공격 페이로드·룰 조건에 쓰인 문자열. 룰의 `content`·정규식이 바꿀 값과 겹치면(예: 룰 조건이 `Host:` 나 `Cookie:` 안에 있음) 아래 '룰 보존 확인'으로 처리한다.

## 7.4 룰 보존 확인

마스킹 뒤 `C.local_check` 와 같은 방식으로 예시가 **여전히 그 룰 조건을 모두 만족하는지** 확인한다.

- 만족 → 마스킹한 예시를 보냄.
- 불만족 (룰 조건이 바꾼 값 안에 있었음) → 그 예시는 **보내지 않음**. 원래 값을 그대로 보내는 길은 두지 않는다. 룰마다 '빠진 예시 수' 를 셈.
- 예시가 모두 빠진 룰은 예시 없이 일반 생성으로 간다 (지금 기존 0건 룰과 같은 흐름).

## 7.5 기록 (증적)

| 위치 | 남길 것 | 남기지 않을 것 |
| --- | --- | --- |
| `_1_requests/_manifest_<세트>.json` 의 `stats` | 마스킹한 예시 수, 바꾼 값 수(종류별), 룰 보존 확인으로 뺀 예시 수 | 원래 값 |
| `_2_generated/<요청>.meta.json` | `existing_examples_sent`, `masked_values` | 원래 값 |
| `logs/3_1_prepare_requests.log` (또는 3.0 로그) | 한 줄 요약 | 원래 값, 예시 본문 |

## 7.6 시험 아이디어

이 프로젝트에는 아직 시험 폴더가 없다. 표준 라이브러리 `unittest` 로 `tests/test_mask.py` 를 만들고 **합성 payload 만** 쓴다 (실제 데이터 금지).

| # | 시험 | 기대 |
| --- | --- | --- |
| T1 | Host·Cookie·Authorization·XFF 가 다 있는 합성 요청 | 각 값이 자리표시 값으로 바뀌고 메서드·경로·공격 부분은 그대로 |
| T2 | **누출 검사**: 합성 비밀값 목록(IP·이메일·JWT·`api_key=...`)을 넣고 마스킹 | 출력에 원래 값이 하나도 없음 (문자열 포함 검사) |
| T3 | 같은 값이 여러 번 | 같은 자리표시 값으로 (예시 안에서 일관) |
| T4 | 두 번 마스킹 (멱등) | 결과가 같음 |
| T5 | 공격 페이로드 안의 IP·URL (예: `wget http://<IP>/x`) | 문서용 IP 로 바뀌어도 룰 조건이 IP 와 무관하면 보존 확인 통과 |
| T6 | 룰 조건이 Cookie 안에 있는 룰 | 마스킹하면 조건 불만족 → 예시가 빠지고 원래 값은 보내지지 않음 |
| T7 | 깨진 요청·바이너리 본문·매우 긴 값 | 예외 없이 처리, 오류면 그 예시를 뺌 (fail closed) |
| T8 | 설정 `참고 예시 마스킹 = 아니오` | 지금과 똑같이 동작 (비교용) |
| T9 | 통합: `python 3_0_run_generation.py --dry-run` + 합성 기존 데이터 | 만들어진 `_1_requests/*.jsonl` 에 T2 의 비밀값 패턴이 없음 |

## 7.7 남는 한계

- 패턴 기반이라 이름이 평범한 파라미터에 든 비밀값(예: `q=<개인 이름>`)은 못 잡을 수 있다. 그래서 `참고 예시 수` = 0 스위치는 그대로 둔다.
- 마스킹으로 예시가 빠지면 그 룰의 생성 품질이 조금 떨어질 수 있다. 빠진 예시 수를 기록해 보고 판단한다.
- LLM 제공자별 데이터 보관·학습 사용 조건 기록은 별도 할 일이다 ([README 다음에 할 일](README.md#다음에-할-일) 2번).
