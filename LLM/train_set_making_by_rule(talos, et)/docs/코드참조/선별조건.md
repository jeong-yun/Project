# 룰 선별 조건

**이 파일이 선별 조건의 원본이다.** `1_2_parse_rules.py`가 실행될 때마다 이 파일의 표를 읽는다.
표를 고치고 저장하면, 다음 실행(`python 1_0_run_daily.py`) 때 **조건이 바뀐 것을 감지해 자동으로 다시 파싱**한다.

## 수정 방법

- **선택** 열에 `O`(추출) 또는 `X`(제외)를 적는다.
- 표는 **위에서부터 차례로** 비교하고, **처음 맞는 줄**을 적용한다. 예외(`X`)는 넓은 패턴(`*`)보다 위에 둔다.
- 어느 줄에도 맞지 않으면 제외된다. 맨 아래 `*` 줄이 그 기본값이다.
- 패턴에는 `*`를 쓸 수 있다. (예: `server-*` = server-로 시작하는 모든 파일)
- **이유** 열은 `04_integrated/<날짜>/selection_report.md`에 그대로 표시된다. (이유만 바꾸면 재파싱하지 않음)
- 표 형식(`|`로 구분)과 아래 제목(`## Talos`, `## ET`, `## 개별 룰`, `## 중복 제거`)은 지워지지 않게 한다.
- 특정 룰 하나만 넣거나 빼려면 `## 개별 룰` 표에 줄을 추가한다 (카테고리 판단보다 우선).
- 선택된 룰 중에서도 **HTTP 룰만** 추출된다.

## 사용자 룰

`00_custom_rules/`(직접 넣은 Snort 룰)의 룰. 카테고리는 msg 로 추정한다.
HTTP 응답 룰 → `response-side`, 방향 불명 → `unknown-side` (먼저 판단), 그 다음 msg 로:
`PUA-OTHER ...` → `pua-other` (Talos 형식), `CUSTOM.1.00001 AI_Agent_...` → `ai`, `CUSTOM.1.00001 server-other_...` → `server-other`, msg 에 `Trojan was detected` → `malware-other`, 그 외(옛 형식은 제품명, 예: `ms`, `adobe`) → 그 단어 또는 `etc`.

- Talos·ET 에 **같은 룰이 있으면 사용자 룰은 뺀다** (Talos·ET 에서 선별 제외된 룰이어도 같으면 뺌 → 이미 제외한 Talos 카테고리가 다시 들어오지 않음). 기준은 아래 `## 중복 제거`와 같다.
- 남은 사용자 고유 룰(AI 해킹 에이전트 등)에 아래 표를 적용한다. 기본은 Talos 선별과 같은 방향 (악성코드·PUA·파일·브라우저 등 제외, 나머지 포함).

| 카테고리 패턴 | 선택 | 이유 |
| --- | :---: | --- |
| response-side | X | HTTP 응답 룰 = 대부분 브라우저·파일 등 클라이언트 측 공격 (Talos 의 browser-*·file-* 제외와 같은 기준). 옛 사용자 룰은 msg 에 제품명만 있어(`MS, IE, ...`) 카테고리로 거를 수 없어서 방향으로 거른다 (2026-10-16) |
| unknown-side | X | 요청/응답 방향을 알 수 없는 룰 (flow 방향·HTTP 버퍼 없음) |
| malware-* | X | 악성코드 통신 (Talos 와 같은 기준) |
| pua-* | X | PUA·애드웨어 |
| file-* | X | 악성 파일 (응답 본문 검사) |
| browser-* | X | 브라우저(클라이언트) 측 공격 |
| os-* | X | 운영체제 취약점 (대부분 비 HTTP·클라이언트) |
| policy-* | X | 정책성 룰 |
| protocol-* | X | 프로토콜 일반 (대부분 비 HTTP) |
| indicator-* | X | 침해·난독화 지표 (Talos 와 같은 기준) |
| * | O | 그 외 (server-*, ai(AI 해킹 에이전트 등), etc 등) — 사용자 고유 룰은 기본 포함 |

## 개별 룰

카테고리와 **상관없이** 특정 룰을 넣거나(`O`) 빼고(`X`) 싶을 때 쓴다. 이 표가 위의 카테고리 표보다 우선한다.
룰 키 = `소스:gid:sid` (예: Talos sid 66203 → `talos:1:66203`, ET sid 2072375 → `et:1:2072375`). HTTP 룰이 아니면 넣어도 추출되지 않는다.

| 룰 키 | 선택 | 이유 |
| --- | :---: | --- |
| talos:1:66203 | O | 최신 LLM 서비스 공격 — Langflow Public Flow 임의 명령 실행 (CVE-2026-33017). Talos `policy-other` 카테고리라 빠져 있었음 (2026-10-16) |

## 중복 제거

Talos와 ET에 **같은 공격을 탐지하는 룰이 양쪽에 있으면**, 통합 결과(`04_integrated/`)에는 한쪽만 남긴다.
소스별 결과(`03_processed/`)는 그대로 두고, 제거한 룰은 `04_integrated/<날짜>/duplicates.json`에 짝과 함께 기록한다.
SID 번호는 소스마다 달라서 비교에 쓸 수 없으므로, 아래 기준으로 '같은 룰'을 판단한다.

| 항목 | 값 | 설명 |
| --- | :---: | --- |
| 사용 | O | O = 중복 제거, X = 양쪽 모두 남김 |
| 남길 소스 | talos | `talos` 또는 `et`. 중복일 때 이 소스의 룰을 남기고 다른 쪽을 뺀다 |
| 기준1 탐지 내용 동일 | O | content(검사 위치·값, 대소문자 무시)와 pcre가 모두 같음. 주로 ET의 GPL 룰(원래 Snort 룰) |
| 기준2 같은 CVE + 같은 경로 | O | CVE가 같고, URI 검사 값 중 경로·파라미터(`/`, `.`, `=` 포함, 영숫자 3자 이상)가 하나 이상 같음 |
