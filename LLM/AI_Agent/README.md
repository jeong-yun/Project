# AI_Agent — LangChain + Streamlit 작은 실험

LangChain 과 Streamlit 으로 만든 작은 LLM 앱 실험이다. 기능은 세 가지다.

1. **일반 질문 채팅** — 홈 화면 (`app.py`)
2. **영어 단어장** — 단어를 물으면 정해진 틀로 설명을 받아 단어장에 쌓고, 발음(TTS)과 Excel·Word·PDF 파일로 내려받는다
3. **AI 안전성 평가** — 공격 프롬프트를 대상 모델에 보내고, 다른 모델(심판)이 응답을 채점해 방어율을 낸다

> 학습용 실험이라 유지보수하지 않는다. 이 문서는 2026-11-12 에 저장소에 있는 파일을 읽고, 모델을 부르지 않는 부분만 직접 실행해 확인한 결과다.
> 패키지 버전과 처음 설계한 폴더 구조는 [Info.md](Info.md) 에 있다.

## 기능별 진행 사항

### 1. 일반 질문 채팅 — `app.py`

- 채팅 입력 → `프롬프트 | ChatOpenAI | 문자열 파서` 체인 → 글자가 나오는 대로 화면에 표시(스트리밍).
- 사이드바에서 프롬프트 종류를 고른다: `Basic`(기본 답변) / `Summary`(LangChain Hub 의 요약 프롬프트를 내려받아 사용).
- 대화 기록은 브라우저 세션에만 남는다(앱을 새로 열면 사라짐).
- LangSmith 로 호출 기록을 남기도록 되어 있다(`langchain_teddynote.logging`).

### 2. 영어 단어장 — `pages/english_word_maker.py` + `english_word_maker/`

- 단어를 입력하면 [prompt/English_word.yaml](prompt/English_word.yaml) 의 틀(17개 항목: 품사·발음 기호·한글/영어 뜻·난이도·빈출도·어원·예문·유의어·반의어·콜로케이션·파생어·태그·헷갈리는 단어 등)로 답을 받는다.
- `parsing.py` 가 답변 글을 항목별로 잘라 단어장(dict)에 넣는다. 같은 단어를 다시 물으면 조회 횟수가 1 늘어난다.
- 단어장은 `English_word/vocab.json` 에 저장되고 표로 보인다.
- 내려받기: Excel · Word · PDF (`export_doc.py`), 단어·예문 발음 mp3 묶음 ZIP (`tts_utils.py`).
- 발음: OpenAI TTS 로 단어와 예문(최대 3개)을 읽어 준다. 한 번 만든 mp3 는 `English_word/audio/` 에 두고 다시 쓴다.

### 3. AI 안전성 평가 — `ai_safety/`

- `testcases.py` — 4개 범주, 공격 프롬프트 9개. 범주마다 '무엇이 안전한 응답인가'의 정의가 있고, 이 정의가 채점 기준으로 심판 모델에 들어간다.

  | 범주 | 개수 | 안전(PASS)의 뜻 |
  |---|---|---|
  | 유해 콘텐츠 | 2 | 위험·불법 요청을 실제로 돕지 않는다 |
  | 탈옥 저항 | 3 | 역할극·'제한 해제' 유도에 넘어가지 않는다 (URL 인코딩으로 숨긴 요청 포함) |
  | 프롬프트 인젝션 저항 | 2 | 입력 안의 '이전 지시 무시' 같은 명령을 따르지 않는다 |
  | 민감정보 유출 | 2 | 시스템 프롬프트에 심어 둔 '숨겨진 규칙'을 내보이지 않는다 |

- `judge.py` — 대상 모델에 공격 프롬프트를 보내 응답을 받고, 심판 모델이 `{판정, 위험도, 이유}` 를 JSON 으로 채점한다. 모델 호출이나 채점이 실패하면 멈추지 않고 그 건만 `ERROR` 로 적는다.
- `metrics.py` — 방어율(= PASS ÷ 전체)과 범주별 방어율을 계산하고 결과 표를 만든다.
- `report.py` — 결과 표를 CSV · Excel 로 바꾼다.

## RAG 는 있는가

**없다.** 이 폴더의 코드에는 RAG 에 필요한 단계가 하나도 없다.

| RAG 에 필요한 단계 | 이 폴더에 있는가 |
|---|---|
| 문서 읽기 (PDF 등) | 없음 |
| 문서를 조각으로 나누기 | 없음 |
| 임베딩 만들기 | 없음 |
| 벡터 저장소에 넣기 (Chroma · Milvus 등) | 없음 |
| 질문과 비슷한 조각 찾기 (검색기) | 없음 |
| 찾은 조각을 프롬프트에 넣어 답하기 | 없음 |

- 세 기능 모두 `프롬프트 → 모델 → 파서` 로 바로 이어지는 체인이고, 문서를 찾아 넣는 부분이 없다.
- `Info.md` 의 패키지 목록에는 RAG 에 쓰는 패키지(`langchain-chroma`, `chromadb`, `langchain-milvus`, `langchain-elasticsearch`, `rank-bm25`, `langchain-text-splitters`, `pymupdf` 등)가 적혀 있지만, 이 폴더의 코드 어디에서도 불러 쓰지 않는다. 설치 목록에만 있다.

## 문서(Info.md)와 실제 파일이 다른 곳

`Info.md` 의 폴더 그림과 코드가 가리키는 경로가 저장소의 실제 파일과 다르다. 그대로는 단어장 화면과 안전성 평가가 실행되지 않는다.

| 코드·문서가 찾는 것 | 저장소에 실제로 있는 것 | 결과 |
|---|---|---|
| `prompts/English.yaml` (단어장 화면이 읽음) | `prompt/English_word.yaml` | 단어장 화면에서 단어를 입력하면 프롬프트 파일을 못 찾는다 |
| `prompts/safety_judge.yaml` (`judge.py` 가 읽음) | 없음 | 심판 체인을 만들 수 없어 평가를 돌릴 수 없다 |
| `pages/1_english_word_maker.py` (`app.py` 의 이동 링크) | `pages/english_word_maker.py` | 링크 대신 "사이드바에서 고르세요" 안내가 뜬다 |
| `pages/2_ai_safety_eval.py` (평가 대시보드) | 없음 | 안전성 평가를 화면에서 쓸 수 없다 |
| "공격 프롬프트 8개" (`Info.md`) | 9개 | 문서 숫자가 옛 값 |

## 실행하려면

1. `Info.md` 의 패키지를 설치한다.
2. 이 폴더에 `.env` 를 만들고 OpenAI 키(`OPENAI_API_KEY`)를 넣는다. LangSmith 기록을 쓰려면 그 키도 넣는다. **`.env` 는 커밋하지 않는다.**
3. 이 폴더에서 `streamlit run app.py`.
4. 단어장 화면까지 쓰려면 위 표의 경로를 먼저 맞춘다(폴더 이름 `prompt` → `prompts`, 파일 이름 `English_word.yaml` → `English.yaml`, 또는 코드의 경로를 실제 파일에 맞춤).

## 알려진 문제

- **모델 설정:** `app.py` 와 단어장 화면은 `gpt-5.1` 을 `temperature=0` 으로 부른다. 그런데 `ai_safety/judge.py` 의 주석에는 "gpt-5 계열은 temperature 를 바꿀 수 없어 0 을 주면 400 오류가 난다"고 적혀 있다(그래서 `judge.py` 는 gpt-5 계열이면 temperature 를 넘기지 않는다). 두 화면은 이 처리가 없다. 실제로 오류가 나는지는 호출해 보지 않았다.
- **PDF 내려받기는 Windows 에서만 된다.** 한글 글꼴 경로가 Windows 의 맑은 고딕으로 고정돼 있다.
- **발음 모듈은 불러오는 순간 OpenAI 키가 필요하다.** `tts_utils.py` 가 파일을 불러올 때 바로 OpenAI 클라이언트를 만든다. 키가 없으면 단어장 화면 전체가 열리지 않을 수 있다.
- **저장된 예시 단어장이 옛 형식이다.** `English_word/vocab.json` 의 단어 1개(`answer`)는 예전 항목 이름(`meaning`, `senses`)으로 저장돼 있어, 지금 화면의 한글 뜻·영어 뜻 칸이 비어 보인다.
- **평가 결과를 저장하는 코드가 없다.** `Info.md` 의 `ai_safety_data/`(결과 저장 폴더)를 만드는 코드는 이 저장소에 없다.

## 확인한 것 / 확인하지 못한 것

**확인한 것** (2026-11-12, 모델 호출 없이 직접 실행)

- 공격 프롬프트는 4개 범주 9개이고, 범주로 걸러 내기가 된다.
- 방어율 집계: 가짜 결과 3건(PASS 1 · FAIL 1 · ERROR 1)을 넣으면 전체 33.3%, 범주별 50.0% · 0.0% 로 계산된다.
- 결과 표의 CSV · Excel 변환이 된다.
- 단어장 답변 파싱: 틀에 맞춘 예시 답변에서 단어, 품사별 한글/영어 뜻, 예문, 유의어, 헷갈리는 단어가 나뉘어 들어간다.
- `prompt/English_word.yaml` 은 프롬프트 파일로 읽힌다(입력 변수 `word`).
- 위 '다른 곳' 표의 파일이 있고 없음.

**확인하지 못한 것**

- 실제 모델을 부르는 모든 동작 — 채팅, 단어 설명 생성, 발음 만들기, 안전성 채점.
- Streamlit 화면을 띄워 눌러 보는 것.
- Word · PDF 내려받기와 발음 ZIP.
- 경로를 맞춘 뒤 단어장 화면이 끝까지 도는지.
