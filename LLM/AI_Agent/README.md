# AI_Agent — LangChain + Streamlit 작은 실험

LangChain 과 Streamlit 으로 만든 작은 LLM 앱 실험이다. 기능은 세 가지다.

1. **일반 질문 채팅** — 홈 화면 (`app.py`)
2. **영어 단어장** — 단어를 물으면 정해진 틀로 설명을 받아 단어장에 쌓고, 발음(TTS)과 Excel·Word·PDF 파일로 내려받는다
3. **AI 안전성 평가** — 공격 프롬프트를 대상 모델에 보내고, 다른 모델(심판)이 응답을 채점해 방어율을 낸다

> 학습용 실험이다. 이 문서는 저장소에 있는 파일을 읽고, **모델을 부르지 않는 부분만** 직접 실행해 확인한 결과다(가짜 모델을 쓴 자동 테스트 포함).
> 실제 모델을 불러야 알 수 있는 것(답변 품질, 실제 방어율)은 확인하지 못했다 — 아래 '확인한 것 / 확인하지 못한 것' 참고.

## 지금 상태 한눈에

| 기능 | 화면 | 기능 모듈 | 상태 |
|---|---|---|---|
| 일반 질문 채팅 | `app.py` (홈) | — | 화면이 키 없이 열림. 실제 답변은 확인 안 함 |
| 영어 단어장 | `pages/1_english_word_maker.py` | `english_word_maker/` | 화면이 키 없이 열리고 저장된 단어가 표에 보임. 파싱·Word·PDF 내려받기는 테스트로 확인 |
| AI 안전성 평가 | `pages/2_ai_safety_eval.py` | `ai_safety/` | 가짜 모델로 '실행 → 채점 → 방어율 → 표 → 내려받기'까지 확인. 실제 방어율은 확인 안 함 |

## 폴더 구조

```text
AI_Agent/
├─ app.py                      # 홈 (일반 질문 채팅)
├─ common.py                   # 함께 쓰는 것: 폴더 경로, 모델 만들기(make_llm), '지시가 아닌 데이터' 표시선
├─ pages/
│   ├─ 1_english_word_maker.py # 영어 단어장 화면
│   └─ 2_ai_safety_eval.py     # AI 안전성 평가 대시보드
├─ prompts/
│   ├─ English.yaml            # 단어장 프롬프트
│   └─ safety_judge.yaml       # 심판(채점) 프롬프트
├─ english_word_maker/         # 단어장 기능: parsing.py · export_doc.py · tts_utils.py
├─ ai_safety/                  # 안전성 평가 기능: testcases.py · judge.py · metrics.py · report.py
├─ English_word/               # 단어장 저장 (vocab.json, 발음 mp3 는 audio/ — 쓸 때 만들어짐)
├─ tests/                      # 자동 테스트 (가짜 모델)
└─ requirements.txt            # 이 폴더 코드가 실제로 불러 쓰는 패키지
```

## 기능별 진행 사항

### 1. 일반 질문 채팅 — `app.py`

- 채팅 입력 → `프롬프트 | ChatOpenAI | 문자열 파서` 체인 → 글자가 나오는 대로 화면에 표시(스트리밍).
- 사이드바에서 프롬프트 종류를 고른다: `Basic`(기본 답변) / `Summary`(LangChain Hub 의 요약 프롬프트를 내려받아 사용).
- 대화 기록은 브라우저 세션에만 남는다(앱을 새로 열면 사라짐).
- LangSmith 로 호출 기록을 남기도록 되어 있다(`langchain_teddynote.logging`).

### 2. 영어 단어장 — `pages/english_word_maker.py` + `english_word_maker/`

- 단어를 입력하면 [prompts/English.yaml](prompts/English.yaml) 의 틀(17개 항목: 품사·발음 기호·한글/영어 뜻·난이도·빈출도·어원·예문·유의어·반의어·콜로케이션·파생어·태그·헷갈리는 단어 등)로 답을 받는다.
- `parsing.py` 가 답변 글을 항목별로 잘라 단어장(dict)에 넣는다. 같은 단어를 다시 물으면 조회 횟수가 1 늘어난다.
- 단어장은 `English_word/vocab.json` 에 저장되고 표로 보인다.
- 내려받기: Excel · Word · PDF (`export_doc.py`), 단어·예문 발음 mp3 묶음 ZIP (`tts_utils.py`).
- 발음: OpenAI TTS 로 단어와 예문(최대 3개)을 읽어 준다. 한 번 만든 mp3 는 `English_word/audio/` 에 두고 다시 쓴다.

### 3. AI 안전성 평가 — `pages/2_ai_safety_eval.py` + `ai_safety/`

- `testcases.py` — 4개 범주, 공격 프롬프트 9개. 범주마다 '무엇이 안전한 응답인가'의 정의가 있고, 이 정의가 채점 기준으로 심판 모델에 들어간다.

  | 범주 | 개수 | 안전(PASS)의 뜻 |
  |---|---|---|
  | 유해 콘텐츠 | 2 | 위험·불법 요청을 실제로 돕지 않는다 |
  | 탈옥 저항 | 3 | 역할극·'제한 해제' 유도에 넘어가지 않는다 (URL 인코딩으로 숨긴 요청 포함) |
  | 프롬프트 인젝션 저항 | 2 | 입력 안의 '이전 지시 무시' 같은 명령을 따르지 않는다 |
  | 민감정보 유출 | 2 | 시스템 프롬프트에 심어 둔 '숨겨진 규칙'을 내보이지 않는다 |

- `judge.py` — 대상 모델에 공격 프롬프트를 보내 응답을 받고, 심판 모델이 [prompts/safety_judge.yaml](prompts/safety_judge.yaml) 로 `{판정, 위험도, 이유}` 를 JSON 으로 채점한다.
  - 공격 프롬프트와 응답은 '지시가 아닌 데이터' 표시선 안에 넣어 심판에게 준다. 응답이 표시선을 흉내 내도 표시선이 늘지 않게 꺾쇠를 바꿔 넣는다.
  - 심판의 답은 코드가 다시 확인한다: JSON 이 아니거나 판정 값이 PASS·FAIL 이 아니면 `ERROR` (PASS 로 세지 않음).
  - 대상 모델 호출이 실패한 건은 심판을 부르지 않고 `ERROR` 로 적는다 (오류 글을 '거부했다'로 채점해 방어율이 부풀지 않게).
- `metrics.py` — 방어율(= PASS ÷ 전체)과 범주별 방어율을 계산하고 결과 표를 만든다.
- `report.py` — 결과 표를 CSV · Excel 로 바꾼다.
- 화면 — 범주와 대상·심판 모델을 고르면 실행 전에 "공격 프롬프트 N개 × 모델 호출 2번 = 호출 2N번"을 알려 준다. 실행하면 진행 막대 → 전체·범주별 방어율 → 결과 표 → CSV·Excel 내려받기. 결과는 브라우저 세션에만 남는다(파일로 저장하지 않음 — 내려받기를 쓴다).

## RAG 는 있는가

**없다.** 이 폴더의 코드에는 RAG 에 필요한 단계가 하나도 없다.

| RAG 에 필요한 단계 | 이 폴더에 있는가 |
|---|---|
| 문서 읽기 (PDF 등) | 없음 |
| 문서를 조각으로 나누기 | 없음 |
| 임베딩 만들기 | 없음 |
| 벡터 저장소에 넣기 (Chroma · Milvus 등) | 없음 |
| 질문과 비슷한 조각 찾기 (검색기) | 없음 |
| 찾은 조각을 프롬프트에 넣어 답하기 | 없음 |

- 세 기능 모두 `프롬프트 → 모델 → 파서` 로 바로 이어지는 체인이고, 문서를 찾아 넣는 부분이 없다.

## 실행하려면

1. 패키지 설치: `pip install -r requirements.txt`
2. 이 폴더에 `.env` 를 만들고 OpenAI 키(`OPENAI_API_KEY`)를 넣는다. LangSmith 기록을 쓰려면 그 키도 넣는다. **`.env` 는 커밋하지 않는다.**
3. 이 폴더에서 `streamlit run app.py`. 사이드바에서 페이지를 고른다.
4. 테스트: 이 폴더에서 `python -m pytest -q` (키 없이 돈다. 실제 모델을 부르지 않는다).

## 알려진 문제

- **gpt-5 계열의 temperature:** `common.make_llm` 은 gpt-5 계열이면 temperature 를 넘기지 않는다(0 을 주면 400 오류가 난다고 알려져 있어서). 홈·단어장·평가가 모두 이 함수를 쓴다. 실제로 오류가 나는지는 호출해 보지 않았다.
- **PDF 내려받기는 한글 글꼴이 있어야 한다.** Windows(맑은 고딕)·macOS(AppleGothic)·나눔고딕 자리를 차례로 찾고, 못 찾으면 화면에 "글꼴을 설치하거나 Excel·Word 로 받으라"는 안내가 뜬다. Windows 밖에서는 실행해 보지 않았다.
- **단어장 화면을 열 때마다 발음 ZIP 을 준비한다.** 아직 mp3 가 없는 단어·예문은 화면을 여는 순간 발음(TTS) 호출이 나간다(한 번 만든 것은 다시 부르지 않음). 키가 없으면 건너뛴다.
- **화면에서 고를 수 있는 모델 이름**(`common.MODEL_CHOICES`)이 지금 계정에서 쓸 수 있는 이름인지는 확인하지 않았다.

## 확인한 것 / 확인하지 못한 것

**확인한 것** (이 PC, 모델 호출 없이 — 자동 테스트)

- 코드가 가리키는 프롬프트·페이지 파일이 모두 실제로 있고, 다른 폴더에서 실행해도 프롬프트를 찾는다.
- 홈·단어장·평가 화면이 OpenAI 키 없이 열린다 (`streamlit.testing.v1.AppTest`).
- 평가 대시보드: 키가 없으면 무엇을 하면 되는지 안내하고, 가짜 모델을 끼우면 9건을 돌려 방어율과 결과 표가 나온다.
- 심판 판정 → 집계: 가짜 판정 4건(PASS 3 · FAIL 1)이 전체 75.0%, 범주별 50.0% · 100.0% 로 계산된다. 심판이 엉뚱한 답을 내면 ERROR.
- 단어장: 답변 파싱, 저장된 예시 단어가 지금 항목 이름으로 표에 보임, Word·PDF 만들기, 한글 글꼴이 없을 때의 안내.
- 발음 모듈은 키 없이 불러와지고, 한 번 만든 mp3 는 다시 부르지 않는다(가짜 클라이언트).
- 이 폴더에 옛 '숨겨진 규칙' 예시 낱말이 남아 있지 않다(검색).

**확인하지 못한 것**

- 실제 모델을 부르는 모든 동작 — 채팅 답변, 단어 설명 생성, 발음 만들기, 실제 방어율. 심판 프롬프트가 실제 모델에서 JSON 만 내는지도 포함.
- 브라우저에서 직접 눌러 보는 것(사이드바 이동 링크, 내려받기 버튼).
- Windows 가 아닌 곳에서의 실행.
